# پک کامل — نصب‌کننده و قالب/افزونه‌های SignTeb MedCore (نسخه ممیزی‌شده)

این بسته، نسخه‌ی کامل، ممیزی‌شده و Production-Ready از نصب‌کننده‌ی خودکار
وردپرس به‌همراه قالب و سه افزونه‌ی همراه است. تمام کد از نظر امنیت (OWASP +
WordPress Security)، سازگاری PHP 8.x، و کیفیت (WPCS) بازبینی و اصلاح شده است.

## ساختار این پک

```
signteb-medcore-audited-pack/
├── README.md                  ← همین فایل
├── AUDIT-LOG.md               ← گزارش کامل تمام ۳۳ باگ پیدا و رفع‌شده (فارسی)
├── CHANGELOG.md               ← خلاصه‌ی تغییرات به زبان ساده
│
├── 1-installer-ready/         ← بسته‌ی آماده‌ی آپلود روی هاست (این را نصب کنید)
│   ├── install.php
│   ├── installer/
│   ├── fonts/
│   ├── diagnose.php
│   └── README.txt             ← راهنمای گام‌به‌گام نصب روی هاست
│
└── 2-source-readable/         ← سورس خوانا (برای بازبینی/ویرایش کد، نه نصب)
    ├── signteb-medcore/       ← قالب
    ├── signteb-medical-core/  ← افزونه‌ی اصلی (موتور نوبت‌دهی/SEO)
    ├── signteb-blocks/        ← افزونه‌ی بلوک‌های گوتنبرگ
    └── signteb-wizard/        ← افزونه‌ی دستیار راه‌اندازی
```

## کدام را استفاده کنم؟

- **برای نصب سایت:** فقط محتوای پوشه‌ی `1-installer-ready/` را در روت هاست
  (public_html) آپلود کنید و در مرورگر به `https://دامنه‌شما/install.php` بروید.
  راهنمای کامل در `1-installer-ready/README.txt` است.

- **برای بازبینی یا ویرایش کد:** پوشه‌ی `2-source-readable/` سورس باز و خوانای
  هر چهار مؤلفه است (همان چیزی که داخل zipهای نصب‌کننده بسته شده). این پوشه
  فقط برای مطالعه/توسعه است؛ برای نصب استفاده نمی‌شود.

> نکته: قالب و افزونه‌ها داخل `1-installer-ready/installer/package/` به‌صورت
> zip آماده‌اند و نصب‌کننده به‌طور خودکار آن‌ها را نصب و فعال می‌کند. نسخه‌ی
> باز و خوانای همان فایل‌ها در `2-source-readable/` قرار دارد.

- **۱۲۸ فایل** بررسی شد، **۳۴ فایل** اصلاح شد، **۳۳ یافته** رفع شد
  (۷ Critical، ۵ High، ۱۲ Medium، ۹ Low).

  رگرسیون بحرانی قالب که کد خام را روی صفحات چاپ می‌کرد.
