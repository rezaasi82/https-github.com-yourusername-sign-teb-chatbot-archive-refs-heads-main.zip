# چک‌لیست ساخت و ارسال پکیج پژکام

> این سند برای لحظه‌ای است که می‌خواهید فایل‌ها را برای راست‌چین بفرستید.
> **کار دستی زیپ نکنید** — `bash build.sh` را اجرا کنید؛ همان بررسی‌های زیر را
> خودکار انجام می‌دهد و اگر چیزی ایراد داشت، اصلاً فایلی نمی‌سازد.

---

## ۱. سه فایل تحویلی و اینکه هرکدام کجا آپلود می‌شود

| فیلد در فرم راست‌چین | فایل | محتوا |
|---|---|---|
| پکیج محصول | `dist/pezhkam-package.zip` | پوشه `pezhkam/` + `pezhkam-guide.pdf` + `pre-install-notes.txt` |
| فایل بروزرسان | `dist/pezhkam.zip` | فقط پوشه `pezhkam/` |
| فایل راهنما | `dist/pezhkam-guide.pdf` | همان PDF، جداگانه |

**اشتباه رایج:** جابه‌جا گذاشتن دو زیپ. «بروزرسان» باید فقط پوشهٔ افزونه باشد،
چون وردپرس مستقیم آن را روی نصب موجود باز می‌کند؛ اگر PDF داخلش باشد، فایل راهنما
داخل پوشهٔ افزونهٔ کاربر کپی می‌شود.

## ۲. ساختار داخل زیپ‌ها

```
pezhkam.zip
└── pezhkam/                     ← پوشه در ریشه زیپ، نه یک لایه عمیق‌تر
    ├── pezhkam.php
    ├── includes/
    │   ├── setup.php
    │   └── RTL_License_0949e1086a8664d9.php
    ├── assets/
    ├── templates/
    ├── languages/
    ├── index.php
    └── uninstall.php

pezhkam-package.zip
├── pezhkam/
├── pezhkam-guide.pdf
└── pre-install-notes.txt
```

اگر بعد از باز کردن زیپ به `pezhkam/pezhkam/` رسیدید، زیپ یک لایه اضافه دارد و
وردپرس افزونه را نمی‌شناسد.

## ۳. بررسی‌هایی که `build.sh` قبل از ساخت انجام می‌دهد

| # | بررسی | چرا مهم است |
|---|---|---|
| ۱ | sha1 فایل `RTL_License_0949e1086a8664d9.php` برابر `7a08b73e…328a54` | یک بایت تغییر = افزونه اصلاً بوت نمی‌شود |
| ۲ | همان هش در `setup.php` و `class-plugin.php` موجود باشد | لایهٔ دوم گیت لایسنس |
| ۳ | `Version:` هدر با `PZK_VERSION` یکی باشد | ناهماهنگی نسخه، آپدیت را خراب می‌کند |
| ۴ | هیچ ایموجی و هیچ entity ایموجی نمانده باشد | ایراد دور آخر بازبین |
| ۵ | هیچ ارجاعی به SignTeb / Pazira / Clinovix / Medora | ایراد «برند شخصی» |
| ۶ | `vazirmatn-variable.woff2` و `OFL.txt` همراه بسته باشند | فونت + شرط مجوز فونت |
| ۷ | `php -l` روی همهٔ فایل‌ها | خطای نحوی = صفحهٔ سفید |
| ۸ | وجود PDF راهنما و نکات قبل از نصب | فیلدهای اجباری فرم |

و بعد از ساخت: هش لایسنس **داخل هر زیپ** دوباره چک می‌شود و زیپ‌ها از نظر
`.DS_Store` / `__MACOSX` / `.git` بررسی می‌شوند.

## ۴. کارهای دستی که اسکریپت انجام نمی‌دهد

- [ ] در `marketing/product-description.html` مقدار `INFOGRAPHIC_URL_HERE` را با
      آدرس واقعی اینفوگرافیک آپلودشده عوض کنید. (تگ `<img>` از قبل `width="960"`
      و `height="5927"` و استایل واکنش‌گرا دارد — به استایل دست نزنید.)
- [ ] اگر صفحهٔ پیش‌نمایش را روی سایتی می‌گذارید، `preview/images/` را هم آپلود کنید.
- [ ] برای نسخهٔ گوتنبرگ (`preview/wordpress-block.html`) تصاویر باید در
      `/wp-content/uploads/pezhkam/images/` باشند — مسیرها در فایل به همین شکل‌اند.
- [ ] `includes/setup.php` را برای انکد ionCube به راست‌چین بفرستید (همان فایلی که
      گیت لایسنس داخلش است).

## ۵. اگر بازبین دوباره ایراد گرفت

قبل از هر تغییری، این را اجرا کنید تا وضعیت فعلی روشن شود:

```bash
bash build.sh          # هر ۸ بررسی + ۳ بررسی بعد از ساخت
```

و برای دیدن اینکه دقیقاً کجا ایموجی یا برند قدیمی مانده:

```bash
grep -rniE "signteb|pazira|clinovix|medora" pezhkam preview marketing \
     --exclude="*.png" --exclude="*.pdf"
```

## ۶. بیلد آزمایشی برای تست روی سایت خودتان

نسخهٔ فروش بدون لودر ionCube و بدون کد فعال‌سازی بالا نمی‌آید، پس برای تست محلی
یک بیلد جدا هست:

```bash
bash build-dev.sh      # -> dist/pezhkam-DEV-NO-LICENSE.zip
```

- گیت لایسنس ندارد: فایل ionCube داخلش نیست، `setup.php` مستقیم بوت می‌کند و
  `Plugin::licensed()` در کپی کوتاه شده است.
- در فهرست افزونه‌ها با نام `Pezhkam (DEV — no licence)` و نسخهٔ `1.0.0-dev`
  دیده می‌شود و یک اخطار دائمی در پنل نشان می‌دهد.
- پوشهٔ `pezhkam/` را دست نمی‌زند؛ همه‌چیز روی کپی موقت انجام می‌شود و اسکریپت
  در پایان sha1 لایسنس سورس را دوباره چک می‌کند.

**این فایل را هرگز به راست‌چین نفرستید.** بدون گیت لایسنس، هر کسی می‌تواند
بدون خرید نصبش کند. سه فیلد فرم فقط از خروجی `build.sh` پر می‌شوند.

## ۷. چیزهایی که هرگز نباید تغییر کنند

- `includes/RTL_License_0949e1086a8664d9.php` — حتی فرمت‌کردن یا تغییر خط پایانی ممنوع.
- ساختار گیت داخل `includes/setup.php`: چک sha1 → `require` → `isActive()` → بوت.
- متد `Plugin::licensed()` — لایهٔ دوم مستقل است؛ حذف آن بای‌پاس را ممکن می‌کند.
- هیچ اطلاعات تماس، لینک شخصی، یا کد پترن پیامکی شخصی داخل هیچ فایلی.
