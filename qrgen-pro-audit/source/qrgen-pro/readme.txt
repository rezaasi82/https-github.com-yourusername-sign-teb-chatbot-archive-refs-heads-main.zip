تولید کننده قدرتمند QR Code با پشتیبانی از انواع محتوا — لینک، متن، ایمیل، تماس، پیامک، وای‌فای و کارت ویزیت.

== Description ==

با شورت‌کد `[qrgen_pro]` (یا نام مستعار `[qrgen]`) یک ابزار کامل تولید QR Code به هر صفحه یا نوشته اضافه کنید. تولید کاملاً در مرورگر کاربر انجام می‌شود؛ رنگ، سایز، فرمت خروجی و لوگو از داخل رابط کاربری قابل تنظیم است.

== Installation ==

1. پوشه پلاگین را در مسیر `wp-content/plugins/` قرار دهید.
2. از بخش «افزونه‌ها» در پیشخوان وردپرس آن را فعال کنید.
3. شورت‌کد `[qrgen_pro]` را در هر صفحه یا نوشته قرار دهید.
4. برای تنظیم مقادیر پیش‌فرض (سایز و رنگ)، به «تنظیمات ← QRGen» مراجعه کنید.

* Improved: اسکریپت خارجی QR فقط در صفحاتی که واقعاً از شورت‌کد استفاده می‌کنند بارگذاری می‌شود.

* Security: افزودن مسیر پاک‌سازی گزینه‌ها هنگام حذف پلاگین (`uninstall.php`) و اعتبارسنجی مقادیر تنظیمات پیش‌فرض.
