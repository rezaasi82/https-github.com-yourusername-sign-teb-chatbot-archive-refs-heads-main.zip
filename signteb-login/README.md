# SignTeb Login

راهکار امنیت و برندسازی صفحه ورود وردپرس برای سایت‌هایی که **SignTeb.com** طراحی می‌کند:

- طراحی اختصاصی مدرن: تم تیره، لهجه‌های طلایی، لوگوی SignTeb، ایکون‌های شناور و پیام خوش‌آمد با نام سایت مشتری
- **تغییر آدرس صفحه ورود** (مخفی‌سازی `wp-login.php` — پاسخ ۴۰۴ به درخواست مستقیم)
- **شخصی‌سازی رنگ سازمانی و لوگو** برای هر مشتری از پیشخوان، بدون کدنویسی
- امضای «طراحی و توسعه: SignTeb.com» زیر فرم (قابل خاموش‌کردن per-client)

پلاگین کاملاً مستقل است و به هیچ پلاگین دیگری وابسته نیست.

## نصب روی سایت مشتری

1. پوشه `signteb-login` را در `wp-content/plugins/` کپی کنید (یا ZIP را از پیشخوان آپلود کنید).
2. پلاگین **SignTeb Login** را فعال کنید.
3. تمام — صفحه ورود بلافاصله طرح جدید را می‌گیرد.

## تنظیمات (پیشخوان ← تنظیمات ← صفحه ورود SignTeb)

| گزینه | توضیح |
|---|---|
| فعال | روشن/خاموش‌کردن کل طراحی اختصاصی |
| آدرس صفحه ورود | مثلاً `vip-login` → ورود از `client.ir/vip-login`؛ `wp-login.php` مسدود (۴۰۴) می‌شود. خالی = غیرفعال |
| رنگ اصلی / رنگ روشن | پالت رنگ طرح برای هر مشتری (پیش‌فرض: طلایی) |
| لوگو | آپلود/انتخاب لوگوی مشتری از کتابخانه پرونده‌ها؛ خالی = نشان SignTeb |
| امضای SignTeb | نمایش یا حذف «طراحی و توسعه: SignTeb.com» |

⚠️ **مهم:** بعد از تنظیم آدرس ورود جدید، آن را یادداشت کنید — `wp-login.php` دیگر باز نمی‌شود. در صورت فراموشی، از WP-CLI اجرا کنید: `wp option update signteb_login_slug ""` یا پوشه پلاگین را موقتاً rename کنید.

## سفارشی‌سازی با کد (اختیاری)

```php
add_filter('signteb_login_enabled', '__return_false');      // خاموش‌کردن کل طرح
add_filter('signteb_login_show_credit', '__return_false');  // حذف امضا
```

## نکات فنی

- CSS فقط در صفحه ورود لود می‌شود؛ هیچ اثری روی سرعت بقیه سایت ندارد.
- تغییر آدرس ورود بدون نیاز به پیوندهای یکتا (pretty permalinks) کار می‌کند؛ لینک‌های خروج، فراموشی رمز و re-auth خودکار به آدرس جدید بازنویسی می‌شوند.
- همه قواعد CSS به `body.signteb-login` محدودند؛ فرم re-auth داخل iframe ظاهر استاندارد وردپرس را حفظ می‌کند.
- ایکون‌های شناور `aria-hidden` و `pointer-events: none` هستند و در حالت `prefers-reduced-motion` ثابت می‌شوند.
- فرم‌های فراموشی رمز، بازنشانی رمز و ثبت‌نام هم همین استایل را می‌گیرند.
