## قواعد مشترک هر چهار صفحه

**۱. استک واقعی سایت:** Xtra + **Elementor Pro** + **Rank Math**. برخلاف فرض Master Promptها، **MedCore و `signteb-blocks` روی signteb.com فعال نیستند** — آن‌ها استک سایت‌های مشتری‌اند. فایل‌های `gutenberg.html` طبق درخواست تحویل شده‌اند و نگاشت Elementor در هر `README.md` آمده.

**۲. اسکیما:** Rank Math خودکار `Organization` / `WebSite` / `BreadcrumbList` / `WebPage` / `Person` / `Article` می‌سازد. هیچ‌کدام را تکرار نکنید. فقط `Service` (و در صورت انتخاب مسیر B، `FAQPage`) دستی اضافه می‌شود.

**۳. FAQPage فقط از یک منبع.** جزئیات در `pillar-01-seo-pezeshki/technical-audit.md` بند ۲.

**۴. هیچ عددی ساختگی نیست.** منبع هر عدد در `technical-audit.md` هر پوشه ثبت شده. توکن‌های `[[PRICE_*]]` و `[[CASE_*]]` عمداً خالی مانده‌اند تا با داده واقعی پر شوند.

```bash
grep -rn "\[\[PRICE_\|\[\[CASE_" signteb-seo/   # باید قبل از انتشار خالی شود
```

**۵. حجم‌ها:** پیلار ۱ ~۱٬۳۴۰ کلمه · پیلار ۲ ~۱٬۲۰۰ · صفحه قیمت ~۹۰۰ · پیلار ۴ ~۱٬۱۵۰.
