# راه‌اندازی SignTeb Video Hub

سه مرحله: ساخت بسته، نصب روی سایت، و (اختیاری) زمان‌بندی بیرونی همگام‌سازی.

---

## ۱. ساخت بسته‌ی قابل نصب

```bash
cd signteb-video-hub
make zip
```

خروجی: `build/signteb-video-hub-1.0.0.zip` (حدود ۱۳۶ کیلوبایت).

`make zip` قبل از بسته‌بندی، بررسی نحوی و تست‌ها را اجرا می‌کند و اگر چیزی خطا داشته باشد بسته ساخته نمی‌شود. فایل‌های توسعه (`tests/`, `Makefile`, `composer.json`) داخل بسته نمی‌روند.

دستورهای دیگر:

| دستور | کار |
|---|---|
| `make check` | بررسی نحوی + تست‌ها — قبل از هر کامیت |
| `make lint` | فقط بررسی نحوی |
| `make test` | فقط تست‌ها (۲۷ assertion) |
| `make clean` | پاک کردن `build/` |

## ۲. نصب روی وردپرس

1. پیشخوان ← **افزونه‌ها ← افزودن ← بارگذاری افزونه** ← فایل ZIP را انتخاب کنید.
2. **فعال‌سازی** کنید. جدول‌ها، موضوعات پیش‌فرض و زمان‌بندی cron خودکار ساخته می‌شوند.
3. **ویدئو هاب ← تنظیمات** → شناسه کانال آپارات را وارد کنید (`drhamedzamani`).
4. دکمه‌ی **تست اتصال** را بزنید — این اولین راستی‌آزمایی واقعی اتصال به API آپارات است.
5. **ویدئو هاب ← داشبورد ← همگام‌سازی دستی**.

پس از اولین همگام‌سازی موفق، آدرس‌های `/videos/` و `/videos/{موضوع}/` فعال می‌شوند. اگر ۴۰۴ گرفتید، **تنظیمات ← پیوندهای یکتا** را باز کنید و بدون تغییر ذخیره کنید تا rewrite rules بازسازی شوند.

### فعال‌سازی هوش مصنوعی (اختیاری)

در همان صفحه‌ی تنظیمات، بخش «هوش مصنوعی»: سرویس‌دهنده را انتخاب، کلید API را وارد و «تولید محتوای هوشمند» را فعال کنید. محتوا در پس‌زمینه و به‌صورت دسته‌ای تولید می‌شود (پیش‌فرض ۳ کار در هر اجرای cron)، نه یکجا.

**انتخاب سرویس‌دهنده روی هاست ایران:** روی بیشتر هاست‌های داخلی، `api.openai.com` و `api.anthropic.com` در دسترس نیستند و اتصال مستقیم با خطای شبکه شکست می‌خورد — این مشکل تنظیمات نیست و با هیچ کلیدی حل نمی‌شود.

| سرویس‌دهنده | آدرس پایه | مناسب برای |
|---|---|---|
| **GapGPT** | خودکار (`api.gapgpt.app/v1`) | هاست ایران — هم مدل‌های GPT و هم Claude را سرو می‌کند |
| Anthropic | مستقیم | سرور خارج از ایران |
| سازگار با OpenAI | دستی وارد کنید | هر درگاه سازگار دیگر |

برای GapGPT فیلد «آدرس پایه سرویس» را **خالی** بگذارید؛ آدرس پیش‌فرض خودکار استفاده می‌شود. بعد از وارد کردن کلید، دکمه‌ی **تست اتصال** کنار همان بخش را بزنید.

> محتوای تولیدشده باید پیش از انتشار توسط پزشک بازبینی شود. پیشنهاد مقاله همیشه پیش‌نویس می‌ماند.

## ۳. زمان‌بندی بیرونی همگام‌سازی (اختیاری)

**چرا لازم است:** WP-Cron وردپرس یک زمان‌بند واقعی نیست — فقط وقتی اجرا می‌شود که کسی از سایت بازدید کند. روی سایت کم‌ترافیک، «همگام‌سازی خودکار هر ۶ ساعت» ممکن است بی‌صدا اجرا نشود.

دو راه وجود دارد. **گزینه‌ی الف بهتر است** اگر به سرور دسترسی دارید.

### الف) کرون واقعی سرور (رایگان، مطمئن‌تر)

در `wp-config.php`:

```php
define('DISABLE_WP_CRON', true);
```

سپس در cPanel ← Cron Jobs (هر ۶ ساعت):

```
0 */6 * * * curl -s https://drhzamani.com/wp-cron.php?doing_wp_cron > /dev/null
```

این کل زمان‌بندی وردپرس را درست می‌کند، نه فقط این افزونه را.

### ب) سناریوی Make.com

سناریو از قبل ساخته شده است:

- **نام:** SignTeb Video Hub — همگام‌سازی زمان‌بندی‌شده
- **شناسه:** `5792346`
- **بازه:** هر ۶ ساعت (۲۱۶۰۰ ثانیه)
- **وضعیت:** **غیرفعال** — تا وقتی رمز را وارد نکنید فعالش نکنید
- **مصرف:** حدود ۱۲۰ عملیات در ماه از سهمیه‌ی ۱۰۰۰تایی پلن رایگان

**برای فعال کردن:**

1. در وردپرس: **کاربران ← پروفایل شما ← Application Passwords**. یک رمز جدید با نام `Make Sync` بسازید و رشته‌ی تولیدشده را کپی کنید. این رمز عبور اصلی شما نیست و هر زمان قابل ابطال است.
2. در Make: سناریو را باز کنید ← روی ماژول HTTP کلیک کنید ← بخش **Advanced settings**:
   - `User name` → نام کاربری وردپرس شما (جای `REPLACE_WITH_WP_USERNAME`)
   - `Password` → رمز Application Password (جای `REPLACE_WITH_APP_PASSWORD`)
3. یک‌بار **Run once** بزنید. پاسخ موفق چنین چیزی است:
   ```json
   {"ok": true, "message": "۳ ویدئوی جدید، ۰ به‌روزرسانی، ۲۷ بدون تغییر.", "data": {...}}
   ```
4. اگر موفق بود، سناریو را **فعال** کنید.

**اگر خطای ۴۰۱ گرفتید:** بعضی هاست‌ها (Apache با CGI/FastCGI) هدر `Authorization` را حذف می‌کنند و احراز هویت هرگز به وردپرس نمی‌رسد. در `.htaccess` اضافه کنید:

```apache
SetEnvIf Authorization "(.*)" HTTP_AUTHORIZATION=$1
```

اگر باز هم کار نکرد، گزینه‌ی الف را استفاده کنید — کرون سرور اصلاً احراز هویت نمی‌خواهد.

## عیب‌یابی

| نشانه | علت محتمل |
|---|---|
| «تست اتصال» آپارات خطا می‌دهد | نام کانال اشتباه است، یا هاست خروجی HTTPS به aparat.com را می‌بندد |
| ویدئوها می‌آیند ولی `/videos/` صفحه‌ی ۴۰۴ می‌دهد | rewrite rules بازسازی نشده — پیوندهای یکتا را ذخیره کنید |
| همگام‌سازی خودکار اجرا نمی‌شود | WP-Cron روی سایت کم‌ترافیک اجرا نمی‌شود — بخش ۳ را ببینید |
| محتوای هوش مصنوعی تولید نمی‌شود | کلید API وارد نشده، یا صف هنوز پردازش نشده — «پردازش صف هوش مصنوعی» را در داشبورد بزنید |
| تست اتصال هوش مصنوعی خطای شبکه/timeout می‌دهد | هاست ایران به سرویس‌دهنده‌ی مستقیم دسترسی ندارد — سرویس‌دهنده را روی GapGPT بگذارید |
| RankMath پیام «نوع پست جدید stvh_video» می‌دهد | طبیعی است. اقدامی لازم نیست؛ برای پرهیز از فهرست تکراری می‌توانید stvh_video را از نقشه سایت RankMath خارج کنید چون این افزونه نقشه سایت ویدئویی اختصاصی خودش را دارد |
| اسکیمای تکراری در تست گوگل | افزونه‌ی سئوی دیگری نودهای صفحه را می‌سازد — این افزونه خودکار کنار می‌کشد؛ اگر باز هم دیدید، گزارش دهید |

آخرین خطاها همیشه در **ویدئو هاب ← داشبورد ← آخرین خطاها** ثبت می‌شوند.
