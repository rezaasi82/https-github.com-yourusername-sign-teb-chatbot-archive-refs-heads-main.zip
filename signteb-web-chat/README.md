# Medora AI — دستیار هوشمند جذب و راهنمایی بیماران

**Medora AI** یک افزونه‌ی وردپرسی **کاملاً مستقل و سفیدبرچسب** است؛ فقط یک چت آنلاین نیست، بلکه یک سیستم هوشمند **جذب بیمار، پاسخ‌گویی خودکار، تولید لید و افزایش نوبت‌دهی** برای پزشکان، کلینیک‌ها و مراکز درمانی. تمام اطلاعات کلینیک را از پنل تنظیمات خودش می‌خواند و روی هر وردپرس تازه‌نصب با هر تمی (حتی Twenty Twenty-Four) بلافاصله کار می‌کند.

**توسعه‌دهنده:** رضا آسیابی · **نسخه:** 2.0.0

## تازه‌های نسخه ۲ (Medora AI)
- 🎯 **جذب لید:** دریافت نام و شماره موبایل پیش از شروع گفتگو.
- 🔥 **امتیازدهی هوشمند لید:** طبقه‌بندی خودکار به لید داغ 🟢 / متوسط 🟡 / سرد ⚪.
- 🧠 **خلاصه خودکار گفتگو:** نام، شماره، موضوع، خدمات موردنیاز و احتمال رزرو.
- 📱 **بازطراحی کامل موبایل:** تمام‌صفحه، سازگار با کیبورد (visualViewport)، دکمه‌های ≥۴۴px، بدون Layout Shift.
- 💳 **کارت حرفه‌ای رزرو نوبت** + دکمه‌های کانال ارتباطی (رزرو 📅 / واتساپ 💬 / تماس 📞 / بله 🟦) با فعال/غیرفعال‌سازی و ردیابی کلیک.
- 📊 **داشبورد آنالیتیکس حرفه‌ای:** گفتگو، لید، لید داغ، نرخ تبدیل، کلیک هر کانال، و نمودار روزانه.
- ✨ آیکون و دکمه‌ی ارسال پریمیوم بازطراحی‌شده.

> نکته‌ی مهندسی: برای پایداری و سازگاری با نصب‌های موجود، پیشوند داخلی کد و اسلاگ افزونه `swc` / `signteb-web-chat` باقی مانده؛ نام تجاری و تمام رشته‌های قابل‌مشاهده برای کاربر «Medora AI» است. ارتقا از نسخه ۱ به ۲ به‌صورت خودکار جدول‌های دیتابیس را مهاجرت می‌دهد (dbDelta).

## ویژگی‌ها

- **سه سرویس‌دهنده‌ی هوش مصنوعی، قابل انتخاب:** Anthropic Claude، OpenAI، یا **GapGPT** (گیت‌وی سازگار با OpenAI و در دسترس از داخل ایران — برای هاست‌هایی که دسترسی مستقیم به `api.openai.com`/`api.anthropic.com` ندارند). در تنظیمات یک Dropdown انتخاب می‌کنید و فیلد کلید + مدلِ همان سرویس بلافاصله (با JS، بدون رفرش) نمایش داده می‌شود. مدل‌ها هاردکد نیستند و قابل تغییر دستی‌اند. پیش‌فرض‌ها: Anthropic → `claude-haiku-4-5-20251001` (سبک و کم‌هزینه)، OpenAI → `gpt-4o-mini`، GapGPT → `gpt-4o-mini` (هم مدل‌های GPT و هم Claude را پشتیبانی می‌کند). اگر سرویس اصلی خطا داد، به‌صورت خودکار به سرویس‌دهنده‌ی دیگرِ پیکربندی‌شده fallback می‌شود.
- **کلید API رمزنگاری‌شده:** کلید هر دو سرویس به‌صورت AES-256 رمزنگاری‌شده در دیتابیس ذخیره می‌شود (نه plaintext).
- **حالت محتوای دستی:** نام کلینیک، تخصص، خدمات و قیمت‌ها، آدرس، تلفن، واتس‌اپ، ساعات کاری و لینک رزرو — همه دستی وارد می‌شوند و در هر درخواست به System Prompt تزریق می‌شوند.
- **لایه‌ی ایمنی پزشکی (غیرقابل‌حذف):** هرگز تشخیص قطعی/تجویز دارو نمی‌دهد؛ در پاسخ‌های مرتبط با علائم، دیسکلیمر اضافه می‌کند؛ در موارد اورژانسی فوراً شماره‌ی اورژانس را نشان داده و مکالمه‌ی AI را متوقف می‌کند. این چک هم در System Prompt و هم در یک لایه‌ی post-processing انجام می‌شود.
- **ویجت سفیدبرچسب (White-label):** رنگ اصلی/ثانویه، نام چت‌بات، آواتار، پیام‌ها، فوتر و جهت (RTL/LTR) همه قابل تغییر کامل‌اند — بدون هیچ برندینگ هاردکد.
- **بدون jQuery:** Vanilla JS خالص، با افکت تایپ طبیعی، دکمه‌های پاسخ سریع، و کارت CTA درون‌خطی (واتس‌اپ/تماس/رزرو) هنگام تشخیص نیت رزرو.
- **بارگذاری مشروط asset:** JS/CSS فقط وقتی ویجت واقعاً رندر می‌شود لود می‌گردد.
- **تاریخچه‌ی مکالمات + آمار:** مشخص‌بودن اینکه کدام مکالمه به CTA تبدیل شده (اثبات ROI)، نرخ تبدیل، و پرتکرارترین پرسش‌ها (ورودی استراتژی سئو).
- **REST + admin-ajax:** اگر هاست REST API را محدود کند، خودکار به admin-ajax سوییچ می‌کند.
- **حالت آزمایشی + لایسنس:** ۵۰ پیام رایگان، سپس نیاز به فعال‌سازی کلید لایسنس سالانه (معماری قابل گسترش به سرور لایسنس).
- **چندزبانه:** فارسی (پیش‌فرض)، عربی و انگلیسی؛ تشخیص خودکار زبان از روی پیام کاربر. فایل `.pot` برای ترجمه آماده است.

## نصب

1. پوشه‌ی `signteb-web-chat` را به `wp-content/plugins/` کپی کنید (یا فایل ZIP را از مسیر «افزونه‌ها ← افزودن ← بارگذاری افزونه» آپلود کنید).
2. افزونه را فعال کنید. در فعال‌سازی، جدول‌های `{prefix}swc_conversations` و `{prefix}swc_messages` ساخته می‌شوند.
3. به منوی **SignTeb Chat** در پیشخوان بروید.

## پیکربندی

تنظیمات در یک صفحه با تب‌های زیر سازمان‌دهی شده‌اند:

| تب | کار |
|---|---|
| **هوش مصنوعی** | انتخاب سرویس‌دهنده، وارد کردن کلید API، انتخاب مدل، لحن، زبان، محدودیت نرخ |
| **اطلاعات کلینیک** | نام، تخصص، تماس، ساعات کاری، شماره اورژانس، لینک رزرو، فهرست خدمات و قیمت‌ها |
| **ظاهر ویجت** | رنگ‌ها، نام چت‌بات، آواتار، جهت، فونت، فوتر، پیام خوش‌آمد، دکمه‌های سریع |
| **تاریخچه مکالمات** | فهرست مکالمات، فیلتر «فقط لیدها»، مشاهده‌ی متن کامل هر مکالمه |
| **آمار** | تعداد مکالمه، نرخ تبدیل CTA، پرتکرارترین پرسش‌ها |
| **لایسنس** | وضعیت نسخه آزمایشی و فعال‌سازی کلید |

### فهرست خدمات
هر خط یک خدمت، با فرمت `نام | قیمت`. مثال:

```
ویزیت عمومی | ۲۵۰ هزار تومان
لیزر موهای زائد | از ۵۰۰ هزار تومان
```

### فونت Vazirmatn (اختیاری)
برای فونت باندل‌شده، فایل `vazirmatn.woff2` را در `assets/fonts/` قرار دهید و گزینه‌ی «فونت باندل‌شده» را فعال کنید. اگر فایل موجود نباشد، افزونه به‌صورت ایمن به فونت سیستمی (Vazirmatn/Tahoma) برمی‌گردد و هیچ خطای 404 نمی‌دهد.

## معماری (برای توسعه‌دهنده)

- **PSR-4-style autoloading:** یک کلاس = یک فایل، با نام‌گذاری `SWC_Foo_Bar` → `class-foo-bar.php`. نگاشت کلاس‌به‌فایل به‌صورت صریح در `includes/class-autoloader.php` تعریف شده تا هرگز یک `require` به فایلی که ساخته نشده اشاره نکند.
- **Interface-driven AI layer:** افزودن سرویس‌دهنده‌ی جدید فقط نیازمند یک کلاس پیاده‌سازی‌کننده‌ی `SWC_AI_Provider_Interface` است.
- **Repository pattern** برای دیتابیس (نه Active Record).
- **محافظت خروجی JSON** با `ob_start()` + `register_shutdown_function` (برای هاست‌هایی که notice چاپ می‌کنند).
- **فراخوانی API** با `wp_remote_post` و timeout حداکثر ۲۲ ثانیه (سازگار با `max_execution_time: 30` هاست‌های ایرانی) و مدیریت کامل خطا — هرگز کرش نمی‌کند.

### Hookها
- اکشن‌ها: `swc_lead_detected`, `swc_message_handled`, `swc_license_status_changed`
- فیلترها: `swc_should_render`, `swc_system_prompt`, `swc_license_is_active`, `swc_trial_limit`

### REST
`POST /wp-json/signteb-web-chat/v1/message` (nonce-protected, rate-limited). در صورت محدودیت REST، fallback به `admin-ajax.php?action=swc_chat_message`.

## ماژول خروجی و اتصال‌ها (Export & Integrations)

از تب **Medora AI ← اتصال‌ها و خروجی** قابل تنظیم است. لیدها = مکالمات ذخیره‌شده در `swc_conversations`/`swc_messages`؛ ماژول خروجی روی همین داده‌ها کار می‌کند و یک جدول لاگ همگام‌سازی (`swc_sync_logs`) اضافه می‌کند.

### ۱) خروجی PDF
از تب «لیدها و مکالمات» روی **دانلود PDF** بزنید. گزارش با طراحی حرفه‌ای، RTL و تاریخ شمسی ساخته می‌شود و در `wp-content/uploads/medora-pdf/YYYY/MM/` با نامی غیرقابل‌حدس ذخیره می‌گردد. دانلود از طریق endpoint امن با بررسی capability و nonce انجام می‌شود.

- اگر روی سایت کتابخانه‌ی **mPDF** یا **Dompdf** نصب باشد، خروجی PDF واقعی تولید می‌شود.
- در غیر این صورت، گزارش به‌صورت HTML آماده‌ی چاپ ذخیره می‌شود (مرورگر با «Print → Save as PDF» فارسی را بی‌نقص رندر می‌کند).

### ۲) Webhook (n8n / Make / Zapier / CRM)
آدرس Webhook و یک Secret وارد کنید. هنگام رویدادها یک `POST` با بدنه‌ی JSON ارسال می‌شود و در صورت تنظیم Secret، هدر امضا هم می‌آید:

```
X-Medora-Event: lead_created
X-Medora-Signature: sha256=<hmac_sha256(body, secret)>
```

نمونه‌ی راستی‌آزمایی امضا در گیرنده (PHP):

```php
$expected = 'sha256=' . hash_hmac('sha256', file_get_contents('php://input'), $secret);
if (hash_equals($expected, $_SERVER['HTTP_X_MEDORA_SIGNATURE'] ?? '')) { /* trusted */ }
```

ساختار payload شامل `lead_id, patient_name, phone, request_type, conversation_summary, pdf_url, created_at, messages[]` است. در صورت خطا و فعال‌بودن «تلاش مجدد»، تا ۳ بار با WP-Cron دوباره تلاش می‌شود و وضعیت در لاگ ثبت می‌گردد.

### ۳) Google Sheets (بدون OAuth، از طریق Apps Script)
نوشتن در Google Sheets نیاز به OAuth دارد؛ به همین دلیل از یک **Google Apps Script Web App** استفاده می‌کنیم. یک اسکریپت ساده مستقر کنید و آدرس `…/exec` آن را در تنظیمات وارد کنید:

```javascript
function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  if (data.secret !== 'YOUR_SECRET') return ContentService.createTextOutput('forbidden');
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName(data.sheet) || ss.insertSheet(data.sheet);
  if (sheet.getLastRow() === 0) sheet.appendRow(data.columns);
  sheet.appendRow(data.row);
  return ContentService.createTextOutput('ok');
}
```

سپس Deploy → New deployment → Web app → Execute as: Me، Who has access: Anyone.

### REST API (فقط ادمین، capability = manage_options)
- `GET /wp-json/medora/v1/leads`
- `GET /wp-json/medora/v1/lead/{id}`
- `POST /wp-json/medora/v1/export/pdf` · `/export/webhook` · `/export/google-sheet` (بدنه: `{ "lead_id": 123 }`)

### امنیت
همه‌ی اکشن‌های خروجی nonce + capability دارند، ورودی‌ها sanitize و SQLها prepared هستند، Secretها رمزنگاری‌شده ذخیره می‌شوند، دانلود فایل فقط از داخل پوشه‌ی `medora-pdf` مجاز است (بدون دسترسی دلخواه به فایل)، و Webhook با امضای HMAC ارسال می‌شود.
